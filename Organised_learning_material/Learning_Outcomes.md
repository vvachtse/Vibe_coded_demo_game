# Learning Outcomes

 LO1 . Learn to properly plan and understand the necessary functions and functionalities of our desired demo

 LO2 . Understanding the relations of different objects design wise

 LO3 . Understanding inheritance and design within the objects used in the game

 LO4 . Understanding how to add new features within the architecture

 LO5 . Understanding how to implement assets (graphical and auditorial)

 LO6 . Design our own game from scratch
 
 LO7 . Creating a demo using Unity (or a different engine) without use of LLMs (except for bug resolutions)

# Progression of the process (parts)

1. Preparation and getting started (LO1)

2. Generating the initial game (HTML) (LO2)

3. Transition to Python (LO3- LO4)

4. Integration of assets (LO 5)

5. Learning our engine of choice

6. Our first game demo (LO 6-7)
